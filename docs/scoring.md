# T11 Правила оценки и ранжирования кандидатов

## 1. Назначение

SmartRecruit AI сравнивает данные резюме с требованиями вакансии и формирует предварительный рейтинг. Окончательное решение принимает рекрутер.

На текущем этапе расчёт проверяется вручную, программная реализация отсутствует.

## 2. Условная вакансия

Для проверки используем вакансию Python-разработчика:

- обязательные навыки: Python и SQL;
- желательный навык: Git;
- требуемый опыт работы с Python: 2 года;
- желательный опыт: хотя бы один проект с использованием Python.

Имя, пол, возраст и фотография кандидата не влияют на оценку.

## 3. Критерии и веса

| Критерий | Вес | Правило выставления баллов |
|---|---:|---|
| Обязательные навыки Python и SQL | 50% | Оба подтверждены — 100 баллов; один — 50; ни один — 0 |
| Продолжительность опыта работы с Python | 30% | 2 года и больше — 100 баллов; от 1 года до 2 лет — 50; меньше 1 года — 0 |
| Проект с использованием Python | 10% | Есть описание хотя бы одного проекта — 100 баллов; явно указано, что проектов нет — 0 |
| Желательный навык Git | 10% | Навык указан — 100 баллов; явно указано, что кандидат им не владеет — 0 |

Сумма весов: 50 + 30 + 10 + 10 = 100%.

Опыт оценивается по продолжительности работы, а проект — по наличию описанного практического примера. Количество лет не начисляет дополнительные баллы за проект.

## 4. Формула итоговой оценки

Итоговая оценка =
баллы за обязательные навыки × 0,50 +
баллы за опыт × 0,30 +
баллы за проект × 0,10 +
баллы за Git × 0,10.

Результат находится в пределах от 0 до 100. Для отображения округляется до одного знака после запятой. Для сортировки используется значение до округления.

Пример:

Кандидат получил:
- навыки — 100;
- опыт — 50;
- проект — 100;
- Git — 0.

Итог: 100 × 0,50 + 50 × 0,30 + 100 × 0,10 + 0 × 0,10 = 75 баллов.

## 5. Отсутствующие и неверные данные

Отсутствие сведений не означает отсутствие навыка.

- Если обязательное поле из T05 отсутствует или заполнено неверно, расчёт не выполняется. Система указывает, что нужно исправить.
- Если поле заполнено, но сведения для отдельного критерия не указаны, критерий получает статус «нет данных».
- Для предварительного расчёта такой критерий даёт 0 баллов, но в объяснении обязательно указывается, что причина — отсутствие сведений.
- Вес критерия не перераспределяется между остальными критериями.
- Кандидат с отсутствующими сведениями получает отметку «требуется уточнение».
- Система не придумывает навыки, опыт или проекты.

Пример: если срок работы с Python не указан, вклад опыта равен 0, а объяснение содержит «Продолжительность опыта не указана; требуется уточнение».

## 6. Обязательные требования

Если кандидат явно не соответствует хотя бы одному обязательному навыку, он получает статус «не соответствует обязательным требованиям».

Если сведения об обязательном навыке отсутствуют, статус — «требуется уточнение».

Кандидаты разделяются на три группы:

1. Все обязательные требования подтверждены.
2. Соответствие обязательным требованиям требует уточнения.
3. Есть подтверждённое несоответствие обязательным требованиям.

Сначала показывается первая группа, затем вторая, затем третья. Внутри каждой группы кандидаты сортируются по итоговым баллам от большего к меньшему.

## 7. Одинаковые баллы

При одинаковом итоговом балле внутри одной группы:

1. Выше располагается кандидат с большим баллом за обязательные навыки.
2. Если он одинаковый — кандидат с большим баллом за опыт.
3. Если эти баллы тоже одинаковы — кандидаты считаются равными по оценке.

Для стабильного отображения равные кандидаты располагаются по условному ID. Это технический порядок, он не означает преимущество одного кандидата.

## 8. Проверочные примеры

Все кандидаты вымышленные. Во всех примерах входные обязательные поля заполнены.

| ID | Навыки | Опыт Python | Проект | Git | Итог | Статус |
|---|---|---|---|---|---:|---|
| K01 | Python и SQL | 3 года | Есть | Есть | 100 | Требования подтверждены |
| K02 | Python и SQL | 1,5 года | Есть | Явно не владеет | 75 | Требования подтверждены |
| K03 | Python; явно не владеет SQL | 2 года | Есть | Есть | 75 | Не соответствует обязательным требованиям |

Расчёты:

- K01: 100 × 0,50 + 100 × 0,30 + 100 × 0,10 + 100 × 0,10 = 100.
- K02: 100 × 0,50 + 50 × 0,30 + 100 × 0,10 + 0 × 0,10 = 75.
- K03: 50 × 0,50 + 100 × 0,30 + 100 × 0,10 + 100 × 0,10 = 75.

Ожидаемый порядок: K01 → K02 → K03.

K02 и K03 имеют одинаковые баллы, но находятся в разных группах: K02 соответствует обязательным требованиям, а K03 — нет.

Дополнительные проверки:

- Два кандидата одной группы с полностью одинаковыми оценками считаются равными; отображаются по ID.
- Если у K01 не указан срок опыта, предварительная оценка составляет 70, появляется отметка об отсутствии данных.
- Отрицательная продолжительность опыта считается ошибкой ввода; расчёт не выполняется.

## 9. Объяснение результата

Для каждого кандидата показываются:

- итоговый балл и статус;
- баллы по каждому критерию;
- сведения резюме, на которых основана оценка;
- отсутствующие данные;
- причина положения в рейтинге.

Пример для K02:

«75 из 100. Python и SQL подтверждены. Опыт Python — 1,5 года, что ниже желательных двух лет. Проект описан. Кандидат указал отсутствие навыка Git».

## 10. Проверка коллегой

Ярослав должен самостоятельно пересчитать три примера, проверить сумму весов, правила пропусков и одинаковых баллов.

Результат проверки и замечания фиксируются в PR. До проведения проверки этот документ является предложением правил.
