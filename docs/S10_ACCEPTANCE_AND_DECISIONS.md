| US-ID | Критерий/сценарий | Ожидание | Факт | Решение |

| US02 | Повторный ID C006 | Ошибка дубликата, нет второй записи | Есть сообщение «Такой ID уже существует. Укажите другой» | **Критерий подтверждён**, US02 в целом ещё не принята |

## Приоритеты: 7 верхних историй (предложение)

1. **US01** — профиль вакансии необходим всем дальнейшим сценариям.
2. **US02** — без надёжного ввода кандидатов рейтинг бессмысленен; проверена защита ID.
3. **US03** — настройка весов определяет метод сравнения и влияет на US04.
4. **US04** — формула баллов наиболее критична для качества решения; приоритет тестирования.
5. **US05** — рейтинг зависит от US04; ничьи проверены частично.
6. **US06** — объяснение позволяет проверить результат и обнаружить несостыковку.
7. **US07** — правка ошибочных данных полезна после стабилизации ядра; только кандидат следующего спринта.

**US08–US10** также кандидаты следующего этапа: уже видимый интерфейс не заменяет AC-тестов. **US11–US12** не включать до завершения RES01. Приоритеты не означают утверждённый состав спринта.
