# SmartRecruit-AI
SmartRecruit AI — учебный проект первичной оценки и ранжирования резюме для IT-рекрутеров. Текущий этап — спецификация и структура прототипа без программной реализации. Команда: Шамхан и Ярослав. Материалы этапа размещены в docs; порядок внесения изменений — CONTRIBUTING.md. Рейтинг помогает рекрутеру анализировать кандидатов, окончательное решение принимает человек. Используем только синтетические примеры. Команды запуска приложения появятся после реализации; сейчас исполняемой программы в этом пакете нет.
