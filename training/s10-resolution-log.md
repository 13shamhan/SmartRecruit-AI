# Задание 10 — учебный конфликт слияния

**Участник:** Шамхан (самостоятельный учебный эксперимент; Ярослав не участвовал).
**Учебная база:** `training/s10-conflict-base`; **рабочую ветку main не изменяли**.

1. Из общей учебной базы созданы две ветки `training/s10-option-a` и `training/s10-option-b`.
2. Обе ветки изменили одну и ту же строку файла `training/s10-merge-demo.txt`.
3. PR #46 из варианта A в учебную базу был слит.
4. PR #47 из варианта B в ту же базу дал **GitHub HTTP 405: Pull Request has merge conflicts** при попытке слияния.
5. Согласованное учебное решение (один участник): выбрать текст `Статус проверки: принят после ручного теста`, поскольку он соответствует проверенному учебному сценарию.
6. В ветке B изменён конфликтующий текст на согласованную версию. Затем PR #47 повторно проверяется и завершается.

## Как могли бы выглядеть конфликтные маркеры Git

```text
<<<<<<< HEAD
Статус проверки: принят после ручного теста
=======
Статус проверки: требуется независимое ревью
>>>>>>> training/s10-option-b
```

Это **иллюстрация формата маркеров** для наглядности, а не снимок выданного GitHub файла. Подтверждение настоящего конфликта — попытка объединить PR #47 с ответом GitHub 405.

**Контроль после решения:** учебный файл содержит одну корректную строку без маркеров. Проверка текстового файла не является сборкой сайта.
